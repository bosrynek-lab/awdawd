# Rynek Shop EXTREME-LITE

Wersja pod bardzo mały RAM. Zero zależności npm.

ACLClouds:
- Main File: `index.js`
- Node.js: 18
- Startup: `exec /usr/local/bin/node --max-old-space-size=64 /home/container/index.js`
- Node Packages: puste

Ustaw `DISCORD_TOKEN` i `GUILD_ID` jako Environment Variables albo w `.env`.
